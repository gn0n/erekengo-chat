# erekengo — AI Agent Chat

Встроенный AI-чат-агент. **created by Yernat Bakytnur**

Отдельное расширение (не связано с `coursera-autopilot`). Работает как в боковой панели Chrome, так и обычной веб-страницей — в том числе с телефона.

## Главное

- **📸 Скриншот → ответ, без разбиения чата.** Кнопка в чате снимает экран (в расширении — `chrome.tabs.captureVisibleTab`), отправляет изображение в vision-модель и показывает краткий ясный ответ. Картинка, вопрос и ответ идут **одним блоком**: отдельного сообщения «пользователь → скриншот» в ленте не появляется (оно уходит только в историю модели). На телефоне — выбор скриншота из галереи.
- **⚡ Отдельные кнопки действий.** На странице Coursera снизу слева плавает мини-панель с двумя кнопками рядом: **«✓ Расставить ответы»** и **«▶ Пропустить видео»**. Те же кнопки продублированы во вкладке «Действия» боковой панели. Первая находит вопросы теста, выбирает варианты встроенным решателем и **ставит ответы прямо в поля, не отправляя тест** (плюс заполняет «Ф. И. О.»). Вторая ускоряет видео и досматривает его. Если вкладка была открыта до перезагрузки расширения и сценарий туда не попал, кнопка сама внедрит агентов через `chrome.scripting.executeScript` и повторит действие — обновлять страницу вручную не нужно.
- **🎬 Категория «Видео Coursera».** Рядом с человеком: когда он открывает видеолекцию на coursera.org, агент досматривает её, нажимает «Пометить как выполненное» и отмечает материал пройденным. Список со статусами, скорость, без звука, статистика сэкономленного времени.
- **Несколько API-ключей с авто-переключением.** Добавляй сколько угодно ключей в «Настройки → Ключи API». Если у активного кончился лимит или он просто не отвечает, агент сам берёт следующий по списку. Ключ с истёкшей квотой ставится на паузу на минуту (`quota`), чтобы не долбить API зря. Активный ключ можно выбрать вручную (★), порядок менять стрелками, каждый ключ проверять отдельно или все сразу.
- **Ошибки человеческим языком.** Вместо `API 429: [{...}]` в чате появится «Лимит ключа исчерпан», вместо 401 — «Неверный API ключ», 404 — «Неверный URL API», снятая модель — «Модель больше не доступна», 5xx — «Сервер API временно недоступен». Внутренние коды остаются только для логики переключения.
- **API-ключи с авто-определением.** OpenAI / OpenRouter / Gemini / Groq / DeepSeek / Together / Mistral / свой URL. Провайдер угадывается по префиксу ключа (`sk-or-` → OpenRouter, `gsk_` → Groq, `AIza`/`AQ.` → Gemini, `sk-` → OpenAI). Кнопка «Определить провайдера» перебирает известные endpoint'ы, если формат неизвестен. Ключ проверяется кнопкой «Проверить ключ».
  - **Важно:** ключ вида `AQ.…` — это новый формат Google Gemini (с 2026 года), а не OpenAI. Расширение само поставит endpoint `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` и подберёт актуальную модель из `/models`. Полный ключ надо копировать из карточки ключа в AI Studio — в списке он показан урезанным.
  - Старые/неверные настройки **чинятся автоматически при загрузке**: если в сохранённом URL не тот endpoint, расширение заменит его само. Модели тоже обновляются сами: агент запрашивает `/models` и берёт актуальную (вместо снятой `gemini-2.5-flash` — например `gemini-3.8-flash`), а при ошибке 404 «model is no longer available» подменяет модель и повторяет запрос без участия человека. Если ошибка осталась — нажми **«Диагностика»**: она покажет статус и тело ответа для каждого endpoint'а.

## Механики, которые я добавил сам

- 4 стиля ответа (кратко, эксперт, код, переводчик) + свой системный промпт.
- Быстрые чипсы-подсказки над полем ввода.
- Перегенерация последнего ответа, копирование, экспорт чата в JSON, очистка.
- Галерея последних 12 скриншотов с миниатюрами в чате.
- Счётчики: сообщения, скриншоты, просмотренные видео.
- Ограничение длины ответа (`max_tokens`), таймаут запроса 90 секунд.
- Автообновление списка видео и статистики из фонового воркера каждые 1.8 с.
- Адаптивный дизайн: мобильная раскладка, нижние табы, безопасный рендер через `textContent`.

## Установка

1. `chrome://extensions` → **Режим разработчика** → **Загрузить распакованное расширение** → папка `erekengo-chat`.
2. Нажми иконку расширения → **Открыть чат** (или правой кнопкой → «Открыть в боковой панели»).
3. В «Настройках» вставь API ключ и модель с поддержкой изображений (`gpt-4o-mini` по умолчанию).
4. Готово: пиши сообщения или жми 📸.

## С телефона

Открой `sidepanel.html` в мобильном браузере (например, с локального сервера или хостинга). Chrome API там нет, поэтому приложение переключается в веб-режим:

- хранит состояние в `localStorage`;
- ключ и запросы идут напрямую в `fetch`;
- 📸 предлагает выбрать скриншот из галереи, 🖼 — загрузить файл;
- авто-просмотр видео работает на текущей странице.

## Структура

- `manifest.json` — MV3, sidePanel, content script на `<all_urls>`.
- `background.js` — состояние, вызовы Chat Completions, захват экрана, статистика видео.
- `video.js` — контент-скрипт только для `coursera.org`: mute, скорость, перемотка в конец, кнопка «Пометить как выполненное», отчёт о просмотре.
- `quizbrain.js` — встроенный решатель тестов (точная база по Git/GitHub + эвристика), без API.
- `quiz.js` — плавающие кнопки «Расставить ответы» / «Пропустить видео» и расстановка ответов в поля теста.
- `app.js` — клиент: чат, скриншоты, категории, API, механики.
- `app.css` — адаптивный дизайн.
- `sidepanel.html` — основной интерфейс (и веб-версия для телефона).
- `popup.html` / `popup.js` — быстрый доступ к панели.
- `standalone.html` — точка входа в веб-версию / options.

## Проверка

Все JS-файлы проходят `node --check`, `manifest.json` — валидный JSON. `verify.js` сверяет, что все `getElementById` из JS присутствуют в HTML, подпись на месте и нет случайных иноязычных вставок. `smoke-test.js` прогоняет фон в моке Chrome API: GET/SET_STATE, API_TEST, CAPTURE, VIDEO_REPORT/PROGRESS, RESET. Оба запускаются командой `node verify.js` и `node smoke-test.js`.
